# Pocket Party

- Build a native SwiftUI, local-first, level-by-level character creator with explicit, pinned rules editions.
- Let AI suggest narrative and mechanical choices; keep rules validation deterministic and authoritative.
- Combine installed packs into one library; preserve each saved character’s pinned rules.
- Keep private packs, source PDFs, and private exports out of this public repository.
- Preserve existing saves and the approved visual direction.
- Never add `Co-Authored-By: Codex` trailers to commits or PR descriptions.

Before working on files, read the matching `paths` rules in `.agents/rules/*.md`. Patterns are repository-relative; read all matching rules, not unrelated ones.
