# Multiclassing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Already approved for continuous execution.

**Goal:** Replay class choices per character level with accurate prerequisites, grants and casting contributions.
**Architecture:** Historical level rows own the class taken. Derive counts from that history, keep starting class immutable except through explicit historical edits, and compose compatible ordinary pools without combining pact/custom pools.
**Tech Stack:** Swift, SwiftUI, typed content data, standalone checks.
**Spec:** `docs/designs/2026-11-12-rules-expansion.md`

## Global Constraints
- Total character level caps at 20.
- Same class in two editions cannot be selected as two classes; canonical class identity and compatibility rules enforce this.
- A custom caster needs an explicit multiclass contribution policy or a clear incompatibility diagnostic.
- Public examples remain original; private definitions remain imported and private.
- Keep existing schema-1 packs and characters readable and evaluable with their current semantics.

## Review Focus
1. A different starting class changes HP/proficiencies, not merely displayed class order.
2. Retroactive edits can invalidate entry prerequisites and later subclass choices.
3. A high combined caster level does not unlock high-level class spell acquisition.
4. Canonical duplicate features/classes cannot stack through aliases/source revisions.
5. Edition rounding is verified from authoritative rules, not inferred from other apps.

**Files:** Create `Sources/FolioCore/Multiclassing.swift`, `Tests/FolioCoreTests/MulticlassChecks.swift`; extend level contracts/capability validation/replay, catalog, `CharacterView.swift`/capability editor, story factual context, `PrintableSheet.swift`, schema/examples/converter/coverage/docs.

Add class entry prerequisites, canonical identity, later-class proficiencies and caster contribution policy to content. Extend `RulesEngine.advance(_:in:classID:)` while keeping old overload. Summary exposes ordered class levels, hit-die capacities, per-class features/subclass/casting.

**Verified primary references (2026-11-12):** [SRD 5.2.1, pp. 24–26](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf) and [SRD 5.1, pp. 56–58](https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf). Both distinguish first-character-level HP from later class entry, total proficiency from class advancement, and spell acquisition from pool capacity. Revised half-caster contributions round up; legacy half contributions round down. Combine ordinary progression only after more than one class actually has Spellcasting; martial plus one caster keeps that caster's own table. Pact is separate despite cross-use permission. Revised fractional policy is one third rounded down, confirmed in [official 2024 Basic Rules, Spellcasting](https://www.dndbeyond.com/sources/dnd/br-2024/creating-a-character#Spellcasting); SRD omits those commercial subclasses, so verify any legacy subclass-specific policy before claiming that pack audited. Use declared generic division/rounding rather than class-name switches.

**Source-audit boundary:** The available legacy SRD and official free 2014 Basic Rules omit Eldritch Knight/Arcane Trickster contributions; the official 2014 PHB page requires purchase. Do not substitute community quotations or Foundry code for primary rules evidence. Original generic fractional-policy tests and verified revised rules can proceed, but no actual legacy fractional-subclass pack is supplied or certified in this delivery.
